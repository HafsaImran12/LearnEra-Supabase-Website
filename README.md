# 🎓 Student Portal

A responsive student portal website built with **HTML, CSS, Bootstrap 5, JavaScript, and Supabase**.

## ✨ Features

* 🔐 User Sign Up & Login
* 👤 User Dashboard
* 📧 User Profile Information
* 🔑 Supabase Authentication
* 🗄️ Supabase Database Integration
* 📱 Responsive Design
* 🔔 SweetAlert Notifications

## 🛠️ Technologies

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Supabase
* SweetAlert2

## 📌 About

This project was created to practice **JavaScript, Supabase Authentication, Database CRUD operations, and responsive UI development**.
