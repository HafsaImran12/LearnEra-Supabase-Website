# 🎓 Student Management System

A responsive Student Management System built with **HTML, CSS, Bootstrap 5, JavaScript, and Supabase**.

## ✨ Features

* 🔐 User Sign Up & Login
* 👤 User Dashboard
* 📧 Display User Email & ID
* 👨‍🎓 Add Student
* ✏️ Edit Student
* 🗑️ Delete Student
* 📋 Display Student Data
* 🔔 SweetAlert Notifications
* 📱 Responsive Design

## 🛠️ Technologies

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Supabase
* SweetAlert2

## 📌 About

This project was created to practice **JavaScript, Supabase Authentication, Database CRUD operations, and responsive UI development**.
